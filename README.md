# Controle avançado: espaço de estados

Material de controle moderno e sistemas dinâmicos: representação em espaço de estados, linearização, controlabilidade e observabilidade, realimentação de estados, observadores e modelos epidemiológicos (SIR, Lotka-Volterra).

**Linguagens:** Matlab · Simulink · Python (Jupyter)

## Estrutura
| Pasta | Conteúdo |
|---|---|
| 1 - Matlab : Octave | Scripts compatíveis com Octave (modelo epidêmico) |
| 2 - Simulink | Modelos SIR e ajuste por erro quadrático |
| 3 - Matlab live script | Modelo de tanque e ajuste de dados |
| 4 - Figuras | Figuras usadas no material |
| 5 - SistemasDinamicos | Apostilas de sistemas dinâmicos (espaço de estados) |
| 6 - 4arquivos_JH | Material de apoio de terceiros |
| Encontro_*.ipynb | Notebooks dos encontros (Python) |

## Como usar
Matlab R2020b ou mais novo com Control System Toolbox e Simulink, ou GNU Octave para a pasta 1. Os notebooks abrem no Google Colab.
